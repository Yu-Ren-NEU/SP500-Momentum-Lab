# SP500 Momentum Lab

在用户 Mac 本机开发的 React + Vite + TypeScript 静态研究工具。界面采用深绿与纸白双主题、明确的数据缺口、简洁参数栏和可对照的年度表，避免用无法证明的历史数据制造漂亮收益。

**当前状态：本机功能已实现，真实指数可回测；1958 年起个股前十完整数据未取得，因此真实 Top N 策略尚不能验收。** 部署依用户要求排在本机功能之后，尚未发布公网。详情见 [验收清单](docs/CHECKLIST.md)。

代码仓库：https://github.com/Yu-Ren-NEU/SP500-Momentum-Lab 。网站与自动部署工作流仍未启用。

## 本机运行

需要 Node.js >=22.18（本机使用 26）、Python 3.9+、curl。Python 无第三方依赖。

```sh
npm ci
npm run dev
```

浏览器访问终端显示的本机地址（默认 http://127.0.0.1:5173）。所有计算在浏览器内运行，无后端、数据库或账户。生产构建：

```sh
npm run check
npm run preview
```

`npm run check` 包括公开数据发布检查、计算/抓取解析/导入检查和 TypeScript + Vite 构建。

## 已实现功能

- 起止年份、初始美元资金、Top N（1-10）；默认并列 Top 1/3/5/10，自定义 N 额外加入。
- 始终呈现标普与纳指基准的图例和结果状态；无覆盖时说明原因，不回填虚构数据。
- 线性/对数资金曲线、曲线按年读数、终值、CAGR、年末最大回撤、逐年回报和跑赢标普年份数。
- 年度前十、下一年初等权配置、持仓金额与年末价值；来源缺失时明确留白。
- CSV 导出。分享链接包含 `start/end/initial/n/data`，固定金融内容版本，旧版本保留在 `public/data/versions/`。
- 本机 JSON 导入：文件仅进入当前标签页内存，不上传、不存储，刷新清除。分享链接不携带此文件；接受者须自行具备相同文件和合法使用权。
- 手机适配、浅色/深色主题、键盘焦点和触控控件。

例：`/?start=2001&end=2002&initial=10000&n=7&data=<实际快照版本>`。无效参数报错，未知快照不会悄悄改用最新数据。链接固定的是公开基准与配置；私有导入不会共享，也不保证重新取得。

## 更新与数据审核

```sh
npm run update
npm run validate
```

Python 下载指定的公开来源，严格验证年度连续性、数值、基准口径和来源，原子替换静态 JSON。金融内容生成 SHA-256 短版本号，历史快照不覆盖。下载/解析失败返回失败，保留上次 `public.json`。抓取原始资料只放 `data/raw/`（忽略且不复制进站点）；WRDS 原始 HTML 不保存，防止外部缓存中可能包含的无关页面元数据进入仓库。

本机离线复现：有已下载的 `data/raw/nyu.html` 与 `data/raw/nasdaq.csv` 时，运行 `python3 scripts/update.py --offline`。离线仅重建抓取时已有的数据，不代表来源刚更新。

公开发布内容受 `scripts/validate_public.py` 的字段允许列表检查；`dist/` 仅由 Vite 生成，不能直接复制项目根目录作为网站。数据源与使用条款见 [来源与覆盖研究](docs/DATA-RESEARCH.md)。

## 导入授权个股资料

先在你有权使用的数据源导出并核验完整年度总回报和成员区间，再按 [导入说明](docs/STOCK-IMPORT.md) 整理。生成浏览器可用 JSON：

```sh
python3 scripts/prepare_stocks.py \
  --annual /本机路径/annual.csv \
  --membership /本机路径/membership.csv \
  --audit /本机路径/audit.json
```

默认输出 `data/private/stocks.json`，不可提交或部署。脚本拒绝将私有结果写入 `public/` 或 `dist/`。网页选择该文件后自动计算策略。

`reviewed` 只表示数据提供者的复核声明，不是程序自动证明数据真实。测试使用明确标注的合成证券，只验证数学逻辑，**没有将合成数据放进公开 JSON，也不能把测试通过称为真实历史策略成立**。

## 计算规则

1. 排名母集：信号年年末真实标普成分，要求有完整自然年总回报；缺完整年度记录的 IPO 必须由复核人明确排除并披露。此规则与“年内任何时候入选过”或“年初成分”不同，不能混用。
2. 排名按该年含分红再投资的总回报降序，相同收益以永久证券标识排序。排序发生在选股之前，不能使用持有年回报决定持仓。
3. 下一年度初等权，年内不再等权重配，下一年年界全额换仓，组合回报为各持仓年度总回报算术平均。
4. 个股年回报必须包含拆股、分红、退市与收购结算。年内清算后的现金按零息持至年末；缺失退市结算不能补成 0。已有含退市的复合回报不能再重复加一次。
5. 少任何一个持仓年度回报或上一年排名，整个请求区间不出该策略曲线，不跳年、不按存活股票重新等权。
6. CAGR = `(终值/初值)^(1/有效年数)-1`。最大回撤包含初始本金峰值，只在年末检查；日频风险可能显著更大。
7. 年末完整信号和年界成交是理想化模型，未模拟下一交易日开盘差价、信号发布延迟、滑点、税费、通胀或可交易性冲击。实盘版本需日频事件与执行价格。
8. 标普从所选起点投入，纳指从所选区间与可用完整年份的交集起点投入同额本金；两者起点不同就不能直接比较最终金额。可选择 1972 年以后的共同起点。
